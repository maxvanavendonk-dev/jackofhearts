Privacy Policy

Jack of Hearts Pipeline. Last updated 19 November 2026.

Who this applies to

The Jack of Hearts Pipeline is a private tool used only by the owner of the Jack of Hearts YouTube channel. It is not offered to the public, and no other person signs in to it.

What data the app accesses

When the channel owner signs in with Google, the app asks for these permissions, and uses them only for the channel owner's own channel:

  • Upload videos (youtube.upload): to upload the channel's own finished videos, with title, description, tags and thumbnail.
  • View the YouTube account (youtube.readonly): to confirm it is connected to the right channel and to check whether a video was already uploaded, so nothing is uploaded twice.
  • View YouTube Analytics reports (yt-analytics.readonly): to read view counts, watch time and similar statistics for the channel's own videos.

How data is stored

The sign-in token and the statistics are stored only on the channel owner's own computer, in a file that only that user account can read. The app has no server and no database outside that computer.

Sharing

Data from Google APIs is not sold, shared with, or transferred to any third party, and it is not used for advertising. It is used only to run the channel as described above.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The app uses YouTube API Services. By using it you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access and data

Access can be revoked at any time on the Google Account permissions page. Deleting the token file on the owner's computer removes all stored sign-in data.

Contact

Questions about this policy: message the Jack of Hearts channel on YouTube.
